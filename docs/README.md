## 프로그래밍 실행 순서
1. 문자열을 입력받는다
   - "덧셈할 문자열을 입력해 주세요.\n"
   - 입력받기
2. 문자열 구분 및 더하기
   - 커스텀 구분자 분리
   - 구분자와 숫자 분리
   - 더하기
3. 결과 실행
## 📋 기능 목록
### 입력
- [ ] 사용자 문자열 입력받기

### 출력하기
- [ ] 출력안내문구 출력하기
  - "덧셈할 문자열을 입력해 주세요.\n"
- [ ] 결과 출력하기
  - "결과 : " + result

### 문자열 구분하기
- [ ] 사용자 문자열을 받아서 구분자와 숫자로 분리하기

### 숫자 더하기
- [ ] 받은 숫자를 더해서 반환하기

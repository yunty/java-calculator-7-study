# 기능 목록

### 게임 진행 순서
1. 게임 시작 / 시작 문구 출력
2. 사용자 입력 받기
3. 계산하기
4. 결과 출력

# 기능 리스트
- 시작 문구 출력하기
  - "덧셈할 문자열을 입력해 주세요."
- 사용자 입력받기 (문자열)
- 입력값 검증하기
- 구분자 구분 하기
- 문자열에서 추출하기
- 문자열 계산하기
- 결과 출력하기
  - "결과 : "

# 책임구분

### 출력하기
- 시작 문구 출력하기
- 결과 출력하기

- 사용자 입력받기

### 구분자
- 구분자 구분하기
- 구분자 제외 숫자 추출하기

### 계산하기
- 문자열 계산
